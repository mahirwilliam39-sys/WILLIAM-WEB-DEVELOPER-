Welcome to Coding Lessons! 🚀

Start with these examples. You can copy each example into a separate HTML file to experiment.

Lesson 1 — HTML Structure

HTML defines the content and structure of a webpage.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>I am learning HTML.</p>
</body>
</html>

Lesson 2 — CSS Styling

CSS controls how your webpage looks.

body {
  background: #07110b;
  color: #65ff9b;
  font-family: Arial, sans-serif;
  text-align: center;
  padding: 30px;
}

h1 {
  text-shadow: 0 0 15px #65ff9b;
}

Lesson 3 — JavaScript Interaction

JavaScript lets your page respond to actions.

const button = document.querySelector("#hello");

button.addEventListener("click", () => {
  alert("Keep learning and building!");
});

Lesson 4 — A Working Button

Add this button to the HTML body and connect it to the JavaScript example above.

<button id="hello">Click Me</button>
